# TikTok Repost Remover — แอป Android + ใช้บนคอม (v3.0.0)

ลบรีโพสต์ของ **บัญชีตัวเอง** ล็อกอินใน TikTok แล้วกดเมนู "ลบรีโพสต์" ได้เลย
ตรรกะสแกน/ลบ/ตรวจสอบพอร์ตมาจากส่วนขยาย v2.1.0 ของ yiitxyz (https://github.com/yiitxyz/tiktok-repost-remover)
ไม่เกี่ยวข้องกับ TikTok อย่างเป็นทางการ

## ในแพ็กเกจนี้
| โฟลเดอร์/ไฟล์ | ใช้ทำอะไร |
|---|---|
| `app/`, `build.gradle`, `settings.gradle` | โปรเจกต์ Android (WebView) สำหรับสร้างไฟล์ **.apk** |
| `.github/workflows/build-apk.yml` | สั่งให้ GitHub สร้าง APK ให้ฟรี (ไม่ต้องลง Android Studio) |
| `web/tiktok-repost-remover.user.js` | สคริปต์สำหรับ **คอม** (Tampermonkey) หรือเบราว์เซอร์มือถือที่รองรับ |
| `dist-extension/` | ส่วนขยาย Chrome ตัวเดิม (ใช้บนคอมได้เลย) |

## สร้างไฟล์ APK (ทำครั้งเดียว ไม่ต้องเขียนโค้ด)
1. สมัคร/ล็อกอิน https://github.com แล้วสร้าง repository ใหม่ (ตั้งเป็น Private ได้)
2. อัปโหลด **ทุกไฟล์ในโฟลเดอร์นี้** ขึ้นไป (ลากวางในหน้าเว็บได้ — ต้องมีโฟลเดอร์ `.github` ติดไปด้วย)
3. ไปแท็บ **Actions** → เลือก **Build APK** → กด **Run workflow**
4. รอ ~3–6 นาที → เปิดงานที่เสร็จ → ล่างสุด **Artifacts** → ดาวน์โหลด `TikTok-Repost-Remover-APK`
5. แตก zip จะได้ `app-debug.apk` → ส่งเข้ามือถือ → เปิดติดตั้ง (อนุญาต "ติดตั้งแอปจากแหล่งที่ไม่รู้จัก")

## วิธีใช้ (แอป Android)
1. เปิดแอป → ล็อกอิน TikTok ในหน้าเว็บ (แนะนำล็อกอินด้วยเบอร์/อีเมล/QR; ปุ่ม Google/Apple มักถูกบล็อกใน WebView)
2. ล็อกอินเสร็จให้กด **↻ รีเฟรช** 1 ครั้ง
3. กด **🧰 ลบรีโพสต์** (หรือปุ่ม ↻ สีแดงมุมขวาล่าง) แล้วเลือก
   - **ลบรีโพสต์ทั้งหมด** = สแกนแล้วลบต่อทันที
   - **สแกนรีโพสต์** → ติ๊กเลือก/ไม่เลือก → **ลบที่เลือก**
4. **เปิดแอปค้างไว้จนขึ้น "ลบเสร็จและตรวจสอบแล้ว"** (จอจะไม่ดับเองขณะแอปเปิดอยู่)
5. ถ้าไม่เห็นรีโพสต์/หาบัญชีไม่เจอ ลองกด **โหมดคอม** แล้วรีเฟรช

## ใช้บนคอม
- **ทางที่ง่ายสุด:** ใช้ส่วนขยาย Chrome ใน `dist-extension/` — `chrome://extensions` → Developer mode → Load unpacked → เลือกโฟลเดอร์ `dist-extension`
- **หรือ** ติดตั้ง Tampermonkey แล้วเปิดไฟล์ `web/tiktok-repost-remover.user.js` → จะมีปุ่ม ↻ มุมขวาล่างในหน้า tiktok.com (หน้าตาเดียวกับในแอป)
- ไฟล์ **.apk ใช้ได้เฉพาะ Android** ติดตั้งบน Windows/Mac ไม่ได้ (ถ้าจะรัน APK บนคอมต้องใช้ Android emulator)

## ข้อควรระวัง
- **การลบย้อนกลับไม่ได้** ใช้กับบัญชีตัวเองเท่านั้น
- ใช้ endpoint ไม่เป็นทางการของ TikTok: อาจใช้ไม่ได้ถ้า TikTok เปลี่ยนระบบ และบัญชีอาจถูกจำกัดได้ แม้มีการหน่วงเวลาแล้ว (ใช้ความเสี่ยงเอง)
- เจอ captcha / 401 / 403 / 429 สคริปต์จะหยุดเอง ให้ยืนยันตัวตน รอสักพัก แล้วกดใหม่
- ข้อมูลทั้งหมดคุยกับ tiktok.com เท่านั้น ไม่ส่งไปที่อื่น
- APK ที่สร้างเป็นแบบ debug (เซ็นด้วยคีย์ debug) เหมาะใช้ส่วนตัว ไม่ได้เตรียมไว้สำหรับขึ้น Play Store
